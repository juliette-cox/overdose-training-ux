# Opioid Overdose Training UX Study

A project made for my human-computer interaction class (CSE 410) exploring online opioid overdose prevention and response education.

## Overview

This project explores two separate design approaches to online opioid 
overdose prevention and response training:

- **End Overdose Training:** An established, free online training course adapted for a general audience.

- **Interactive Prototype:** A scenario-based prototype
  designed in Figma.

  Participants complete both trainings and then provide feedback through brief questionnares.

  ## Built With 

  - HTML, CSS, Javascript
  - Figma
  - Tally 
  - Github Pages
